existing `VM` volume in OpenCore, reaching the login screen. QMP screenshot,

user-supplied password; the corrected password unlocked the guest through QMP.

unrelated processes were stopped. Terminal eventually opened successfully.

using the authenticated Change Password form. Verified the replacement using
`dscl . -authonly restoredelight`, which returned `PASSWORD_AUTH_EXIT:0`.
The new random password is saved on the host with mode 0600 at
`~/Machines/macos-tahoe/vmctl-login-password`. No password values are stored in
this report or repository. The old account password is superseded.

Saved `vmctl.json` with the verified account and checkout
`/Users/restoredelight/lewdware`, `vmctl-layout=us`, and `vmctl-ram=4G`.
A localhost SSH probe did not find an answering SSH service; Remote Login setup
is still pending.

Host available memory fell to 363 MiB with all 8 GiB swap occupied during
unrelated compilation. Guest app/settings launches took several minutes.
After password verification, initiated a normal authenticated `shutdown -h now`.
After shutdown, host available memory recovered to 4.5 GiB, still below the
6 GiB required for this 4 GiB guest plus headroom. Do not resume macOS until
host memory again meets guest RAM plus 2 GiB headroom.
No unrelated host processes were killed or modified.

Both VMs are confirmed stopped. macOS completed normal authenticated shutdown;
