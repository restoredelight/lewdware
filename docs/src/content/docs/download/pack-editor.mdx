title: Download Pack Editor
description: The Lewdware Pack Editor comes with Lewdware.
---

The Lewdware Pack Editor is a graphical tool for creating and editing packs — import media, assign tags,
embed modes, and export for distribution.

It is installed with Lewdware: [download Lewdware](/download/) for your platform, and the pack
editor is there beside it, as its own app.

If you installed the pack editor on its own before, installing Lewdware replaces it.
