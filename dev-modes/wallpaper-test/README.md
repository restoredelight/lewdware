# Wallpaper test

Build with `lw mode build`. Use only with the synthetic pack generated by
`deploy/vm/make-wallpaper-pack.py OUTPUT --source EXACT_SOURCE_CHECKOUT`.
The source checkout selects the runtime pack schema/version; use the exact CI
revision for an installed older build. The generator needs Python 3.11+.

Enable the application's wallpaper permission. The `scenario` option selects:

- `explicit`: A at startup, B after 15 seconds, reset after 30, exit after 40.
- `completion`: A at startup, B after 15 seconds, exit after 30.
- `hold`: A remains until the session stops.
- `missing`: look up a nonexistent image, verify nil, leave wallpaper unchanged.

Capture the original raw desktop settings before starting, inspect the visible
desktop during each stage, then verify exact restoration before resetting a VM.
Normal Lua exit currently triggers an erroneous supervisor restart; see
`deploy/vm/reports/ubuntu-wallpaper-2026-11-09.md`.
